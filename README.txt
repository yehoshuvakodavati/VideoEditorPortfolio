RUDHRA - 3D VIDEO EDITOR PORTFOLIO
==================================

1. Put your photo here:        assets/photo.jpg   (portrait / 4:5 works best)
2. Put your 3 videos here:     assets/videos/video1.mp4, video2.mp4, video3.mp4
   - Use H.264 .mp4, 1080p or lower, ideally under 25 MB each so the site loads fast.
   - Optional: make a SHORT (5-10 s, 720p, small) loop for the 3D screens and set it as
     "preview" in config.js. The full video still plays when a visitor clicks it.
3. Open config.js and change the titles, descriptions and your email.
4. Go to https://app.netlify.com/drop and drag this whole folder in. Done.

To test on your computer, do NOT double-click index.html (browsers block modules from files).
Run this in the folder instead:   npx serve     then open the address it prints.
